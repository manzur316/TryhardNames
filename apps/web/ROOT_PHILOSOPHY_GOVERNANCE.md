# Root Philosophy Governance — TryhardNames

Operational framework for brand and product decisions. **Not** marketing copy. **Not** a technical system.

**Purpose:** Every new branch (route, tool, SEO page, lane, product) must pass the same trunk — so growth stays one cultural universe, not parallel dialects.

---

## 1. Root philosophy (official)

**Statement:**

> **TryhardNames helps people shape how they are read online — with readable, plausible, restrained identity signals — across games, bios, and text.**

**Operational meaning:**

- **Primary job:** identity legibility in public digital spaces (lobby, feed, Discord, tags), not “more random strings.”
- **Method:** typography-first thinking, social plausibility, and restraint over noise.
- **Not the root:** “gaming generators,” “SEO traffic,” or “content volume.” Those are **branches**, not the soil.

**One-line checkpoint:** *Would this still make sense if we removed “gaming” from the sentence?* If yes, the root is identity-in-public; gaming is the largest scene, not the definition.

---

## 2. Brand principles (non-negotiable, actionable)

| Principle | Do | Don’t |
|-----------|----|--------|
| **Readability** | Prefer strings that scan fast at small sizes and in feeds | Dense symbols, unreadable spam, “clever” clutter |
| **Restraint** | One strong accent per surface; quiet hierarchy | Rainbow gradients, badge stacks, competing focal points |
| **Plausibility** | Outputs and copy feel like something a real person would run | Lore cosplay, fake rarity economies, parody names as default |
| **Calm prestige** | Understated confidence in tone and layout | Hype, flex language, “insane / cracked” framing |
| **Discovery atmosphere** | Variation in rhythm and emphasis without gamifying pulls | Slot-machine psychology, “spin again” energy |
| **Typography-first hierarchy** | Type and spacing carry meaning; words as objects | Illustration-first, mascot-first, logo-first |
| **Anti-sludge** | Cut filler words and template swagger | SEO swagger, AI hype, “ultimate generator” |

---

## 3. Prohibited language (brand surfaces)

Use **never** in hero copy, primary CTAs, navigation labels, or above-the-fold product voice — unless inside a clearly marked **SEO / acquisition** block (see §7).

- Ultra-rare, epic, insane, cracked (as hype), god-tier, legendary (for names/tools)
- AI-powered, neural, infinite names, viral naming
- Best names ever, #1 generator, ultimate tryhard
- Random / chaos as the **primary** promise (sampling is fine; chaos-as-brand is not)
- Slot-machine framing: “roll,” “pull,” “jackpot,” “loot” for identity outputs
- Fake exclusivity: “only for pros,” “secret list” (unless literally true and documented)

**Allowed elsewhere with care:** technical SEO phrases in body content; keyword-forward headings **below** the brand layer.

---

## 4. Prohibited visual energy (brand layers)

**Avoid as default** on home, hubs, and primary generator shells:

- Full-viewport **gaming SaaS** gradients on every hero
- RGB / neon emphasis as the **main** brand signature
- “Casino” motion: aggressive pulse, constant shimmer on CTAs
- Badge stacks that read **loot / rarity** as the headline emotion
- Hover theatrics on **every** card (lift + glow + scale together)

**Not the same as minimal-only:** color and contrast are allowed; **emotional control** is required. One loud moment per view is a ceiling, not zero.

---

## 5. Trunk checklist (every new branch must pass)

Before ship, answer **yes** or fix:

1. **Universe:** Does this feel part of the same identity culture (not a separate product)?
2. **Plausibility:** Would a skeptical user believe these outputs could exist in the wild?
3. **Reading:** Does UI prioritize legibility and calm hierarchy over noise?
4. **Discovery:** Does pacing feel like exploration, not a reward loop?
5. **Tone:** Is the voice calm / observational in brand layers (not hype)?
6. **Restraint:** Is there at most one dominant accent (color, motion, or metaphor)?
7. **Typography:** Does type carry the story without relying on gimmick graphics?
8. **Root:** Does it advance “how you’re read online” — not only “more outputs”?

**Failure mode:** “Technically great SEO” or “high CTR copy” that fails 1–2 → **revise brand layer**, keep utility under the fold.

---

## 6. Generator reframing rules

**Positioning:** Generators are **identity exploration tools**, not output machines.

| From (machine) | To (exploration) |
|------------------|-------------------|
| Generate | Sample · Explore · Open set · Refine |
| Shuffle | Reshuffle · New draw · Another pass |
| Remix variations | Adjacent styles · Same lane, different read |
| Ultra / Rare / Stylish (headline emotion) | Move to secondary meta or remove from primary framing |
| “More names” as hero | “How this reads in [scene]” as hero |

**Utility preserved:** batch size, speed, filters, copy buttons — unchanged. **Language and hierarchy** change so the tool reinforces the root.

## 7. SEO governance

**Two layers:**

| Layer | Role | Voice |
|-------|------|--------|
| **Brand layer** | First screen, nav, hub intros, lane framing | Root philosophy, calm, identity-focused |
| **Acquisition layer** | Long-form blocks, FAQs, meta descriptions, keyword-rich H2s | SEO-clear, explanatory, can be more literal |

**Rules:**

- Brand layer **never** carries prohibited language (§3) or casino energy (§4).
- Acquisition layer **may** use search-aligned phrases if truthful — **below** or **clearly separated** from brand blocks (e.g., standard SEO section at bottom).
- **Do not** let acquisition copy **replace** the brand headline on the same URL.

**What can be SEO-friendly without contaminating emotion:** structured headings, internal links, concrete examples, FAQs — written **matter-of-fact**, not hype.

---

## 8. Typography governance (direction)

**Intent:** Typography is the **primary visual system** for brand coherence across branches — not Orbitron-as-default-everywhere.

| Axis | Direction |
|------|-----------|
| **Hierarchy** | Few sizes; strong contrast between title / body / meta |
| **Spacing** | More silence between blocks than competitor generators |
| **Restraint** | One display voice per surface; avoid sci-fi display + neon + rarity badges competing |
| **Readability** | Body fonts optimized for reading paragraphs; names in monospace or semibold where scan matters |
| **Wearable continuity** | Brand moments should work as **word-first** artifacts (future physical / social) |

**Practical rule:** Marketing heroes drift toward **neutral editorial** sans + calm weight; **game-scene** pages may keep stronger display **inside** the branch if the trunk checklist passes.

---

## 9. Future branch governance

**Before adding a hub, game vertical, utility, or capsule:**

1. **Branch thesis (one paragraph):** Who is being read, in what scene, under what constraint?
2. **Trunk checklist (§5):** Full pass.
3. **Dialect guard:** No new verbs for “make names” unless added to a **shared glossary** (avoid ten synonyms for Generate).
4. **Visual kit:** Pick from shared tokens (chips, spacing, accent) — custom skins need design sign-off.
5. **SEO plan:** Brand layer vs acquisition layer mapped before writing.

**Apparel / objects later:** Same thesis + trunk + typography continuity; no new philosophy per SKU.

---

## 10. Governance model: root → trunk → branches → leaves

| Level | What it is | Governed by |
|-------|------------|-------------|
| **Root** | Philosophy statement (§1) | Immutable without explicit revision |
| **Trunk** | Principles (§2), checklist (§5), language/visual bans (§3–4), typography direction (§8) | Every release touching user-facing identity |
| **Branches** | Hubs, games, stylish text, symbols, major tools | Branch thesis + trunk + reframing rules (§6) |
| **Leaves** | Individual URLs, variants, long-tail SEO | Acquisition rules (§7); must still pass plausibility + anti-sludge |

**Growth rule:** New code or pages **never** skip trunk because “it’s just SEO” or “just a small tool.” Leaves still inherit root.

## Test final

For every new surface:

> **If we removed the logo, would a stranger still say this is about *how identity is read online* — not “another name toy”?**

If yes → ship. If no → adjust brand layer; keep SEO and engines intact underneath.
